# Marquee Jainil

A collection of front-end practice projects built with HTML and CSS.

## Projects

- **BookMyShow** — movie and live-event landing page inspired by modern ticket-booking interfaces.
- **Profile** — profile UI practice.

## BookMyShow

The BookMyShow project focuses on layout composition, movie cards, promotional banners, event collections, typography, spacing, and responsive styling.

## Tech Stack

- CSS3
- Local media assets

## Running locally

Open `BookMyShow/index.html` in a modern browser.
